# ATS2 для Zed

Подсветка синтаксиса ATS2 (Applied Type System 2)
в Zed edtior

## Поддерживается

- Подсветка синтаксиса ATS2
- Файлы с расширением `.dats`, `.sats`, `.hats` 
- Объявления функций и переменных
- Статические параметры и типы
- Алгебраические типы данных и конструкторы
- Pattern matching (непереводимо в контексте)
- Escape-последовательности и строковые литералы
- Встроенные блоки на языке `C`

## Для установки нужно

1. Клонировать репозиторий:

   ```sh
   git clone https://github.com/cutie-full-of-charm/zed-ats2.git
   ```

2. Открыть Zed editor
3. В палитру команд (`Ctrl+Shift+P`)
4. Run `zed: install dev extension`
5. Выбраьт корень клонированной `zed-ats2` директории

Открыть любой `.dats`, `.sats` или `.hats` файл, также можно открыть файл `test_highlight_here.dats`, сохраненный прямо в репозитории для теста

## Ограничения

Расширение предоставляет только подсветку синтаксиса, без проверок типов, lsp и т.п.

## Лицензия

Код лицензирован на условиях MPL 2.0
